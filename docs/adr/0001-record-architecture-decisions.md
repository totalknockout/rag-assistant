# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-17

## Context

This is a portfolio project. Reviewers want to see not only what was built but
why, and which options were rejected.

## Decision

Record every significant decision as a short ADR in `docs/adr/`, numbered in
order, using `0000-template.md`. Supersede rather than edit accepted ADRs.

## Consequences

Decisions are reviewable in pull requests alongside the code they affect. Each
ADR should link to evidence, such as an evaluation report or a cost figure,
wherever one exists.
